# Tailwind CSS v4：CSS-first 配置时代

Tailwind v4 是一次重大架构升级，最大的变化是**用 CSS 文件取代 `tailwind.config.js`**。所有配置通过 CSS 指令完成。

## 从 v3 到 v4

v3 用 JavaScript 配置：

```js
// tailwind.config.js (v3)
module.exports = {
  darkMode: "class",
  theme: {
    extend: {
      colors: { primary: "#3b82f6" },
    },
  },
  plugins: [require("@tailwindcss/typography")],
};
```

v4 用 CSS 配置：

```css
/* globals.css (v4) */
@import "tailwindcss";
@plugin "@tailwindcss/typography";
@custom-variant dark (&:where(.dark, .dark *));

@theme {
  --color-primary: #3b82f6;
}
```

## @theme 指令

`@theme` 定义设计 token，自动生成对应的工具类：

```css
@theme {
  /* 颜色 → 生成 bg-primary、text-primary 等 */
  --color-primary: #3b82f6;
  --color-primary-dark: #2563eb;

  /* 字体 → 生成 font-sans、font-mono */
  --font-sans: "Inter", system-ui, sans-serif;
  --font-mono: "JetBrains Mono", monospace;

  /* 间距 → 生成 p-xs、m-xs 等 */
  --spacing-xs: 0.5rem;
}
```

## class-based 深色模式

v4 默认用 `prefers-color-scheme` 媒体查询。如果要配合 `next-themes` 的 `class` 模式，必须声明 `@custom-variant`：

```css
/* 声明 dark: 变体基于 .dark 类，而非媒体查询 */
@custom-variant dark (&:where(.dark, .dark *));

/* 现在可以这样用 */
/* <div className="bg-white dark:bg-gray-900"> */
```

不声明这行，`dark:bg-gray-900` 只在系统深色模式下生效，点击切换按钮无效。

## @plugin 加载插件

```css
@plugin "@tailwindcss/typography";
@plugin "@tailwindcss/forms";
```

也可以传配置：

```css
@plugin "@tailwindcss/typography" {
  className: "wysiwyg";
}
```

## PostCSS 配置

v4 的 PostCSS 插件包名变了：

```js
// postcss.config.mjs
export default {
  plugins: {
    "@tailwindcss/postcss": {},
  },
};
```

注意是 `@tailwindcss/postcss`，不是 v3 的 `tailwindcss`。

## 代码高亮双主题示例

一个实际用例：Shiki 双主题通过 CSS 变量切换，无需重新渲染：

```css
/* 浅色模式用 --shiki-light */
code[data-theme*=" "] span {
  color: var(--shiki-light);
}

/* 深色模式用 --shiki-dark */
.dark code[data-theme*=" "] span {
  color: var(--shiki-dark);
}
```

## 小结

v4 的 CSS-first 配置更符合 Web 标准，消除了 JS 配置与 CSS 之间的隔阂。迁移时注意 `@custom-variant dark` 声明和 PostCSS 插件名变更。
