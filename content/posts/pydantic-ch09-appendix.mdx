## B. 常用装饰器速查

| 装饰器 | 用途 | 示例 |
|--------|------|------|
| `@field_validator` | 字段验证器 | `@field_validator('field')` |
| `@model_validator` | 模型验证器 | `@model_validator(mode='after')` |
| `@field_serializer` | 字段序列化器 | `@field_serializer('field')` |
| `@model_serializer` | 模型序列化器 | `@model_serializer(mode='wrap')` |

### B.1 field_validator

```python
from pydantic import BaseModel, field_validator

class User(BaseModel):
    age: int
    
    @field_validator('age')
    @classmethod
    def validate_age(cls, v):
        if v < 0:
            raise ValueError('年龄不能为负')
        return v
```

### B.2 model_validator

```python
from typing_extensions import Self
from pydantic import BaseModel, model_validator

class User(BaseModel):
    password: str
    confirm: str
    
    @model_validator(mode='after')
    def check_match(self) -> Self:
        if self.password != self.confirm:
            raise ValueError('密码不匹配')
        return self
```

### B.3 field_serializer

```python
from pydantic import BaseModel, field_serializer
from datetime import datetime

class Event(BaseModel):
    name: str
    created_at: datetime
    
    @field_serializer('created_at')
    def serialize_dt(self, dt: datetime):
        return dt.strftime('%Y-%m-%d')
```

## C. 验证器执行顺序

验证器按以下顺序执行：

1. **Before 验证器**（从右到左）
   ```python
   @field_validator('field', mode='before')  # 3
   @field_validator('field', mode='before')  # 2
   @field_validator('field', mode='before')  # 1 ← 先执行
   ```

2. **内部验证**
   - 类型转换
   - 约束检查
   - 默认值填充

3. **After 验证器**（从左到右）
   ```python
   @field_validator('field', mode='after')  # 1 ← 先执行
   @field_validator('field', mode='after')  # 2
   @field_validator('field', mode='after')  # 3
   ```

4. **Wrap 验证器**
   ```python
   @field_validator('field', mode='wrap')
   def validator(cls, v, handler):
       # 可以调用handler执行内部验证
       return handler(v)
   ```

## D. 配置选项速查表

| 配置项 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `frozen` | bool | 冻结模型（不可变） | `frozen=True` |
| `extra` | str | 额外字段处理 | `'ignore'`, `'forbid'`, `'allow'` |
| `from_attributes` | bool | 从对象属性创建 | `from_attributes=True` |
| `populate_by_name` | bool | 按字段名填充 | `populate_by_name=True` |
| `str_to_lower` | bool | 字符串转小写 | `str_to_lower=True` |
| `str_to_upper` | bool | 字符串转大写 | `str_to_upper=True` |
| `str_strip_whitespace` | bool | 去除字符串空白 | `str_strip_whitespace=True` |
| `str_min_length` | int | 字符串最小长度 | `str_min_length=1` |
| `str_max_length` | int | 字符串最大长度 | `str_max_length=100` |
| `strict` | bool | 严格模式 | `strict=True` |
| `validate_assignment` | bool | 赋值时验证 | `validate_assignment=True` |
| `arbitrary_types_allowed` | bool | 允许任意类型 | `arbitrary_types_allowed=True` |
| `ser_json_timedelta` | str | timedelta序列化格式 | `'iso8601'`, `'float'` |
| `ser_json_bytes` | str | bytes序列化格式 | `'utf8'`, `'base64'` |

### 完整配置示例

```python
from pydantic import BaseModel, ConfigDict

class Model(BaseModel):
    model_config = ConfigDict(
        # 模型行为
        frozen=False,                    # 是否冻结
        extra='ignore',                  # 额外字段: 'ignore', 'forbid', 'allow'
        from_attributes=True,            # 从对象创建
        populate_by_name=True,           # 按名称填充
        
        # 字符串处理
        str_to_lower=False,              # 转小写
        str_to_upper=False,              # 转大写
        str_strip_whitespace=False,      # 去空白
        str_min_length=0,                # 最小长度
        str_max_length=None,             # 最大长度
        
        # 验证
        strict=False,                    # 严格模式
        validate_assignment=False,       # 赋值时验证
        arbitrary_types_allowed=False,   # 允许任意类型
        
        # 序列化
        ser_json_timedelta='iso8601',    # timedelta格式
        ser_json_bytes='utf8',           # bytes格式
    )
```

## E. 错误类型速查

| 错误类型 | 说明 | 示例 |
|----------|------|------|
| `int_parsing` | 整数解析错误 | `"abc"` → int |
| `int_from_float` | 浮点转整数错误 | `1.5` → int |
| `string_type` | 字符串类型错误 | `123` → str |
| `string_too_short` | 字符串太短 | `"a"` (min=5) |
| `string_too_long` | 字符串太长 | `"abc..."` (max=5) |
| `value_error` | 值错误 | 自定义验证失败 |
| `missing` | 字段缺失 | 必填字段未提供 |
| `none_required` | 要求None | 提供了非None值 |
| `bool_parsing` | 布尔解析错误 | `"yes"` → bool |
| `float_parsing` | 浮点解析错误 | `"abc"` → float |
| `list_type` | 列表类型错误 | `"abc"` → list |
| `dict_type` | 字典类型错误 | `"abc"` → dict |

### 错误处理示例

```python
from pydantic import BaseModel, ValidationError

class User(BaseModel):
    id: int
    name: str

try:
    user = User(id='abc', name=123)
except ValidationError as e:
    for error in e.errors():
        print(f"字段: {error['loc']}")
        print(f"类型: {error['type']}")
        print(f"消息: {error['msg']}")
        print(f"输入: {error['input']}")
        print('---')
```
