# TypeScript 泛型进阶：约束、条件类型与推断

泛型是 TypeScript 类型系统的核心能力。本文覆盖从基础到进阶的关键模式。

## 泛型基础

泛型让函数和类型可复用，类型参数在调用时确定：

```typescript
// 泛型函数：T 是类型参数
function identity<T>(value: T): T {
  return value;
}

const num = identity(42);        // 类型推断为 number
const str = identity<string>("hi"); // 显式指定为 string
```

## 泛型约束（extends）

用 `extends` 限制类型参数必须满足某个结构：

```typescript
// T 必须包含 length 属性
function getLength<T extends { length: number }>(item: T): number {
  return item.length;
}

getLength("hello");    // 5
getLength([1, 2, 3]);  // 3
// getLength(123);     // 抙错：number 没有 length
```

```typescript
// 用 keyof 约束属性名
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { name: "Alice", age: 30 };
getProperty(user, "name"); // 返回 string
getProperty(user, "age");  // 返回 number
// getProperty(user, "email"); // 抙错
```

## 条件类型

根据类型关系选择不同类型，类似三元运算符：

```typescript
// 如果 T 是 string 的子类型，返回 boolean，否则返回 number
type Result<T> = T extends string ? boolean : number;

type A = Result<string>;  // boolean
type B = Result<number>;  // number
```

## infer 关键字

在条件类型中**推断**类型变量：

```typescript
// 提取函数返回值类型
type ReturnType<T> = T extends (...args: never[]) => infer R ? R : never;

type Fn = () => string;
type R = ReturnType<Fn>; // string
```

```typescript
// 提取 Promise 的值类型
type Awaited<T> = T extends Promise<infer U> ? U : T;

type Data = Awaited<Promise<number>>; // number
```

```typescript
// 提取数组元素类型
type ElementOf<T> = T extends (infer E)[] ? E : never;

type Item = ElementOf<string[]>; // string
```

## 实战：类型安全的 API 封装

```typescript
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

// 泛型请求函数
async function request<T>(url: string): Promise<ApiResponse<T>> {
  const res = await fetch(url);
  return res.json();
}

// 使用时类型安全
const { data } = await request<User[]>("/api/users");
//    ^? User[]
```

## 映射类型

基于现有类型生成新类型：

```typescript
// 所有属性变为可选
type Optional<T> = {
  [K in keyof T]?: T[K];
};

// 所有属性变为只读
type Readonly<T> = {
  readonly [K in keyof T]: T[K];
};

interface User {
  name: string;
  age: number;
}

type OptionalUser = Optional<User>;
// { name?: string; age?: number }
```

## 小结

泛型进阶的核心工具：`extends`（约束）、条件类型（分支）、`infer`（推断）。组合使用能构建出表达力极强的类型抽象，在保证类型安全的同时避免重复。
