> 上一章我们学会了变量——一个变量存一个值。但如果你有100个名字要存呢？100个变量显然不现实。这一章教你用**列表**把一堆数据装进一个变量里。

## 什么是列表？

列表就像一排抽屉，每个抽屉编了号（从0开始），里面可以放东西。用方括号 `[]` 表示，中间用逗号分隔。

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']
```

现在 `bicycles` 这一个变量里，装了4辆自行车品牌。

## 如何访问列表中的元素？

列表里每个位置有个编号，叫**索引**。从0开始：

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

print(bicycles[0])    # trek  （第1个）
print(bicycles[1])    # cannondale  （第2个）
print(bicycles[3])    # specialized  （第4个）
```

**小技巧**：索引 `-1` 永远指向最后一个元素，`-2` 指向倒数第二个，以此类推。这在不知道列表有多长的时候特别有用。

```python
print(bicycles[-1])   # specialized （最后一个）
```

## 修改、添加和删除元素

列表嘛，核心就是"能改"。

### 修改：直接覆盖

```python
motorcycles = ['honda', 'yamaha', 'suzuki']
motorcycles[0] = 'ducati'   # 直接改第0个
# 现在是 ['ducati', 'yamaha', 'suzuki']
```

### 添加：末尾加 or 插队

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

motorcycles.append('ducati')
# 现在是 ['honda', 'yamaha', 'suzuki', 'ducati']
# append() 加在最后，很常用

motorcycles.insert(0, 'harley')
# 现在是 ['harley', 'honda', 'yamaha', 'suzuki', 'ducati']
# insert() 可以插到任意位置
```

### 删除：三种方式，各有各的用场

**方式一：`del` 直接删**
```python
del motorcycles[0]
# 删掉第0个，再也访问不到
```

**方式二：`pop()` 弹出来**
```python
popped = motorcycles.pop()
# 删掉最后一个，但把它"弹出来"存进 popped，以后还能用
# 这在做队列、栈的时候特别有用
```

**方式三：`remove()` 按值删**
```python
motorcycles.remove('ducati')
# 删掉第一个遇到的 'ducati'
# 注意：如果列表里有多个 'ducati'，只删第一个
```

## 组织列表：排序

列表里的元素乱糟糟？来排个序。

### 永久排序：`sort()`

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']
cars.sort()
# 现在 cars 变成了 ['audi', 'bmw', 'subaru', 'toyota']
# 注意：这是永久改变，无法恢复

cars.sort(reverse=True)
# 反向永久排序
```

### 临时排序：`sorted()`

想看看排好序是什么样，但不想真的改原始列表？用 `sorted()`：

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']

print(sorted(cars))        # 排好序了，但 cars 本身没变
print(sorted(cars, reverse=True))  # 反向临时排序
```

### 反转列表：`reverse()`

```python
cars.reverse()
# 直接把顺序倒过来，不是按字母，是单纯倒序
```

### 列表长度：`len()`

想知道列表里有多少个元素？

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']
print(len(cars))   # 4
```

## 常见的坑：索引错误

用列表最常遇到的错误是 `IndexError`，通常发生在：

- 访问一个**空列表**的 `-1` 位置
- 列表只有3个元素，却访问索引 `5`

```python
empty_list = []
print(empty_list[-1])   # ❌ IndexError！
```

遇到索引错误时，试着把索引减1，或者 `print(len(my_list))` 看看列表到底有多长。
