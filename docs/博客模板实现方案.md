## 关键文件实现思路

### 1. `lib/mdx-options.ts` — MDX 编译选项

```typescript
import remarkGfm from "remark-gfm";
import rehypePrettyCode from "rehype-pretty-code";
import type { MDXRemoteProps } from "next-mdx-remote/rsc";

export const mdxOptions: MDXRemoteProps["options"] = {
  mdxOptions: {
    remarkPlugins: [remarkGfm],
    rehypePlugins: [
      [rehypePrettyCode, {
        theme: {
          light: "github-light",
          dark: "github-dark-dimmed",
        },
        keepBackground: false,  // 关键: 让 CSS 控制背景, 而非硬编码主题背景
      }],
    ],
  },
};
```

**要点**：
- `remark-gfm` 启用表格、删除线、任务列表、自动链接，博客必需
- `rehype-pretty-code` 配置双主题对象 `{ light, dark }`，插件会为每个 token 生成 `--shiki-light` 和 `--shiki-dark` 两套 CSS 变量
- `keepBackground: false` 让背景色由 CSS 控制，便于与站点深色模式协调

### 2. `lib/posts.ts` — 数据层

```typescript
import fs from "fs";
import path from "path";
import matter from "gray-matter";

const POSTS_DIR = path.join(process.cwd(), "content", "posts");
const PER_PAGE = 5;

// 读取单个文件 → { slug, frontmatter, content }
function readPostFile(fileName: string) {
  const filePath = path.join(POSTS_DIR, fileName);
  const source = fs.readFileSync(filePath, "utf8");
  const { content, data } = matter(source);
  return { slug: fileName.replace(/\.mdx$/, ""), content, ...(data as PostFrontmatter) };
}

// 获取所有文章元数据 (按日期降序)
export function getAllPosts(): PostMeta[] {
  const files = fs.readdirSync(POSTS_DIR).filter(f => f.endsWith(".mdx"));
  return files.map(readPostFile)
    .map(({ content, ...meta }) => meta)
    .sort((a, b) => new Date(b.date).getTime() - new Date(a.date).getTime());
}

// 获取单篇文章 (含正文)
export function getPostBySlug(slug: string): Post | null { ... }

// 获取所有标签 (去重 + 计数)
export function getAllTags(): Tag[] { ... }

// 按标签筛选
export function getPostsByTag(tag: string): PostMeta[] { ... }

// 分页: { posts, totalPages, currentPage }
export function getPaginatedPosts(page = 1, perPage = PER_PAGE) { ... }
```

**要点**：所有函数同步实现（`fs.readdirSync`），在服务端组件中直接调用，无需 async。排序按 `date` 降序。`getAllPosts` 剔除 content 只返回元数据用于列表页。

### 3. `types/index.ts` — 类型定义

```typescript
export interface PostFrontmatter {
  title: string;
  date: string;          // ISO 8601: "2025-08-01"
  excerpt: string;
  tags: string[];
  draft?: boolean;
}

export interface PostMeta extends PostFrontmatter {
  slug: string;
}

export interface Post extends PostMeta {
  content: string;       // gray-matter 解析后的 MDX 正文 (不含 frontmatter)
}

export interface Tag {
  name: string;
  count: number;
}
```

### 4. `components/MDXContent.tsx` — MDX 渲染器

```tsx
import { MDXRemote } from "next-mdx-remote/rsc";
import { mdxOptions } from "@/lib/mdx-options";
import { mdxComponents } from "@/components/mdx-components";

export function MDXContent({ source }: { source: string }) {
  return (
    <div className="prose dark:prose-invert max-w-none">
      <MDXRemote
        source={source}
        options={mdxOptions}
        components={mdxComponents}
      />
    </div>
  );
}
```

**要点**：
- `MDXRemote` 从 `next-mdx-remote/rsc` 导入，是 async 服务端组件
- `source` 传入 gray-matter 解析后的**纯正文**（已剥离 frontmatter）
- 用 `prose dark:prose-invert` 包裹实现排版 + 深色模式适配
- `components` 映射自定义组件（可选：`a`→外链处理、`pre`→CodeBlock 加复制按钮）

### 5. `app/posts/[slug]/page.tsx` — 文章详情页

```tsx
import { getAllPosts, getPostBySlug } from "@/lib/posts";
import { MDXContent } from "@/components/MDXContent";
import { notFound } from "next/navigation";

export function generateStaticParams() {
  return getAllPosts().map(post => ({ slug: post.slug }));
}

export function generateMetadata({ params }): Metadata {
  const post = getPostBySlug(params.slug);
  if (!post) return {};
  return {
    title: post.title,
    description: post.excerpt,
    openGraph: {
      title: post.title,
      description: post.excerpt,
      type: "article",
      publishedTime: post.date,
      tags: post.tags,
    },
  };
}

export default function PostPage({ params }) {
  const post = getPostBySlug(params.slug);
  if (!post) notFound();
  return (
    <article>
      <header>... title, date, tags ...</header>
      <MDXContent source={post.content} />
    </article>
  );
}
```

### 6. `app/globals.css` — Tailwind v4 + 代码高亮 CSS

```css
/* === Tailwind v4 入口 === */
@import "tailwindcss";
@plugin "@tailwindcss/typography";

/* class-based 深色模式 (配合 next-themes attribute="class") */
@custom-variant dark (&:where(.dark, .dark *));

/* === 自定义主题 token === */
@theme {
  --color-primary: #3b82f6;
  --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;
  --font-mono: "JetBrains Mono", ui-monospace, monospace;
}

/* === rehype-pretty-code 双主题切换 (核心 CSS) === */
/* 默认 (light): 使用 --shiki-light 变量 */
code[data-theme*=" "],
code[data-theme*=" "] span {
  color: var(--shiki-light);
  background-color: var(--shiki-light-bg);
}

/* dark 模式: 使用 --shiki-dark 变量 (.dark 由 next-themes 添加到 <html>) */
.dark code[data-theme*=" "],
.dark code[data-theme*=" "] span {
  color: var(--shiki-dark);
  background-color: var(--shiki-dark-bg);
}

/* 代码块基础样式 */
pre {
  padding: 1rem;
  border-radius: 0.5rem;
  overflow-x: auto;
}
```

**要点**：
- `@import "tailwindcss"` 替代 v3 的 `@tailwind base/components/utilities`
- `@plugin "@tailwindcss/typography"` 在 v4 中加载插件的方式
- `@custom-variant dark` 必须声明，否则 `dark:` 工具类默认走 `prefers-color-scheme` 媒体查询
- `code[data-theme*=" "]` 选择器匹配 rehype-pretty-code 生成的带双主题的 code 元素（data-theme 属性值为空格分隔的双主题名）
- 通过 `.dark` 前缀切换 CSS 变量，**无需重新渲染**代码块

### 7. `components/ThemeProvider.tsx` — next-themes 包装

### 9. 分页路由设计

- 首页 `/` = 第1页（直接调 `getPaginatedPosts(1)`）
- `/page/[page]` = 第2页起（`generateStaticParams` 生成 2~totalPages 的页码）
- 每页 `PER_PAGE = 5` 篇
- `Pagination` 组件根据 `currentPage` / `totalPages` 渲染上下页链接

```tsx
// app/page/[page]/page.tsx
export function generateStaticParams() {
  const { totalPages } = getPaginatedPosts();
  return Array.from({ length: totalPages - 1 }, (_, i) => ({
    page: String(i + 2),  // 生成 2, 3, 4...
  }));
}
```

### 10. `app/sitemap.ts` — SEO sitemap

```tsx
import { getAllPosts, getAllTags } from "@/lib/posts";

export default function sitemap(): MetadataRoute.Sitemap {
  const posts = getAllPosts().map(p => ({
    url: `https://example.com/posts/${p.slug}`,
    lastModified: new Date(p.date),
  }));
  const tags = getAllTags().map(t => ({
    url: `https://example.com/tags/${t.name}`,
  }));
  return [
    { url: "https://example.com" },
    { url: "https://example.com/about" },
    { url: "https://example.com/tags" },
    ...posts,
    ...tags,
  ];
}
```

## 潜在坑点与注意事项

1. **shiki 版本与 Node 版本**：运行环境 Node 22.22.2，用 shiki@^3.0.0（Node>=18）。若未来移植到 Node 18 环境，需降级到 shiki@^1.0.0（rehype-pretty-code 0.14 peerDep 兼容 ^1|^2|^3|^4）。**README 中注明 Node >=18 要求**。

2. **next-themes 水合不匹配**：`<html>` 标签必须加 `suppressHydrationWarning`，否则 next-themes 在客户端注入 `class="dark"` 会触发 React 水合警告。ThemeToggle 组件需用 `mounted` 状态守卫，避免服务端渲染时图标不匹配。

3. **rehype-pretty-code CSS 选择器**：双主题模式下，生成的 code 元素 `data-theme` 属性值为空格分隔的两主题名（如 `"github-light github-dark-dimmed"`）。CSS 必须用 `code[data-theme*=" "]`（注意空格），不能用 `code[data-theme="light"]`。`keepBackground: false` 必须设置，否则主题背景色硬编码无法随 CSS 切换。

4. **gray-matter 与 MDXRemote 的配合**：用 gray-matter 先剥离 frontmatter，再把**纯正文**传给 `MDXRemote` 的 `source`。不要用 `parseFrontmatter: true`（那是 compileMDX 的功能，且 MDX frontmatter 语法与 YAML frontmatter 不同）。

5. **Tailwind v4 prose 深色模式**：`prose dark:prose-invert` 依赖 `dark:` 变体，必须先声明 `@custom-variant dark (&:where(.dark, .dark *))`。若忘记声明，`dark:prose-invert` 不生效，文章正文在深色模式下不可读。

6. **generateStaticParams 中 getPostBySlug**：`generateStaticParams` 只需 slug 列表（调 `getAllPosts` 即可），不要在参数生成阶段读文件内容。文件读取在页面渲染时按需进行。

7. **分页边界**：首页 `/` 是第1页，`/page/1` 不应存在（避免重复内容 SEO 问题）。`generateStaticParams` 只生成 page >= 2 的参数。Pagination 组件的"上一页"在第2页时应链接到 `/` 而非 `/page/1`。

8. **content/posts 目录需纳入构建**：MDX 文件是运行时读取的（非编译时），`fs.readFileSync` 在 Vercel 等 serverless 环境的构建阶段可用，但需确保 `content/` 目录被部署。Next.js 默认包含项目根目录下所有文件，无需额外配置。
