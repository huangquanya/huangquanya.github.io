> 学会了列表的基本操作，这一章往前走一步——学会用 `for` 循环把列表里的元素一个个拿出来处理。这是 Python 里最常用的语法之一，学完你就能真正"批量处理"数据了。

## 用 for 循环遍历列表

列表最常见的操作是什么？把里面的每个元素都处理一遍。Python 用 `for` 循环来实现：

```python
magicians = ['alice', 'david', 'carolina']

for magician in magicians:
    print(magician.title() + ", that was a great trick!")
    print("I can't wait to see your next trick, " + magician.title() + ".\n")

print("Thank you, everyone. That was a great magic show!")
```

运行结果：

```
Alice, that was a great trick!
I can't wait to see your next trick, Alice.

David, that was a great trick!
I can't wait to see your next trick, David.

Carolina, that was a great trick!
I can't wait to see your next trick, Carolina.

Thank you, everyone. That was a great magic show!
```

注意看最后一句 `Thank you...` 没有缩进——它不在循环里，所以只执行一次。这就是 Python 缩进的意义：**缩进决定代码属于哪里**。

### 变量命名的小建议

```python
# 列表用复数，元素用单数
cats = ['lion', 'tiger', 'panther']
for cat in cats:
    print(cat)
```

一眼就能看出 `cats` 是列表、`cat` 是一个元素，代码可读性更好。

## 缩进错误：Python最常见的坑

Python 用缩进来标记代码块，所以缩进错误是新手最常踩的坑。来看5种典型错误：

### 1. 忘记缩进

```python
for cat in cats:
print(cat)   # ❌ IndentationError
```

for 循环后的代码必须缩进。

### 2. 循环内多条语句漏了缩进

```python
for cat in cats:
    print(cat)
print(cat)   # ❌ 这行本应在循环内，但因为没缩进变成只执行最后一次
```

### 3. 不必要的缩进

```python
    print("hello")   # ❌ 在没有缩进上下文的地方缩进了
```

### 4. 循环后多余的缩进

```python
for cat in cats:
    print(cat)

    print("Done")   # ❌ 本应在循环外，因为多了缩进变成循环的一部分
```

### 5. 漏掉冒号

```python
for cat in cats   # ❌ 少了冒号
    print(cat)
```

## 创建数值列表：range() 和列表解析

### range() 生成数字序列

```python
for value in range(1, 6):
    print(value)   # 1, 2, 3, 4, 5
```

**注意**：`range(1, 6)` 生成的是 1 到 5，**不包含 6**——Python 里"差一行为"是常事。

### 转换成列表

```python
numbers = list(range(1, 6))
print(numbers)   # [1, 2, 3, 4, 5]
```

### 步长：隔几个数取一个

```python
even_numbers = list(range(2, 11, 2))
print(even_numbers)   # [2, 4, 6, 8, 10]
# 第三个参数2表示"每次跳2步"
```

### 统计函数

```python
digits = [1, 2, 3, 4, 5]

print(min(digits))   # 1  最小值
print(max(digits))   # 5  最大值
print(sum(digits))   # 15  总和
```

### 列表解析：一行生成整个列表

这是 Python 的招牌写法，比写循环再 append 简洁得多：

```python
# 传统写法
squares = []
for value in range(1, 11):
    squares.append(value ** 2)

# 列表解析（一行搞定）
squares = [value**2 for value in range(1, 11)]
print(squares)   # [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
```

## 使用列表的一部分：切片

切片就是取列表的"一段"，语法是 `列表[起点:终点]`：

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

print(players[0:3])    # ['charles', 'martina', 'michael']  前三个
print(players[:4])      # 前四个（省略起点，默认从0开始）
print(players[2:])      # ['michael', 'florence', 'eli']     第三到最后
print(players[-3:])     # ['michael', 'florence', 'eli']     最后三个
```

### 遍历切片

```python
for player in players[:3]:
    print(player.title())
# 只处理前三名玩家
```

### 复制列表（必须用切片！）

```python
my_foods = ['pizza', 'burger', 'sushi']

# 正确：用切片复制，两者是独立列表
friend_foods = my_foods[:]

# 错误：两个变量指向同一个列表！
friend_foods = my_foods
```

区分方法：修改 `my_foods`，看 `friend_foods` 变不变——变了就是错误做法。

## 元组：不可变的列表

列表可以随便改，但有时候你不想数据被改——比如屏幕分辨率、游戏窗口大小。这种场景用**元组**。

```python
dimensions = (200, 50)

print(dimensions[0])   # 200
print(dimensions[1])   # 50
```

元组用圆括号 `()`，**不能修改元素**：

```python
dimensions[0] = 250   # ❌ TypeError!
```

但可以重新给元组变量**赋值**（整个换掉）：

```python
dimensions = (400, 100)   # ✅ 重新赋值，可以
```

元组也可以用 for 循环遍历：

```python
for dimension in dimensions:
    print(dimension)
```

## PEP 8：代码格式规范

Python 有一套官方的代码风格指南，叫 **PEP 8**。记住这几个核心要点：

- 每级缩进用 **4个空格**（不用 Tab）
- 每行不超过 **80个字符**
- 运算符前后、逗号后加空格，如 `squares = [x**2 for x in range(1, 11)]`
- 空行合理分隔代码的不同部分

遵守 PEP 8 不是强制的，但能让你的代码更易读，也更"Pythonic"。
