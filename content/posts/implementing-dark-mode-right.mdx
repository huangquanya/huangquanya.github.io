# 深色模式最佳实践：next-themes + Tailwind v4

深色模式看似简单，但要做到无闪烁、无水合警告、SEO 友好，有不少细节。

## next-themes 基础

`next-themes` 通过在 `<html>` 上切换 class 实现深色模式：

```tsx
// components/ThemeProvider.tsx
"use client";
import { ThemeProvider as NextThemesProvider } from "next-themes";

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  return (
    <NextThemesProvider
      attribute="class"
      defaultTheme="system"
      enableSystem
      disableTransitionOnChange
    >
      {children}
    </NextThemesProvider>
  );
}
```

`attribute="class"` 会在 `<html>` 上添加 `.dark` 类。`disableTransitionOnChange` 避免切换时的颜色过渡动画。

## 根布局的 suppressHydrationWarning

next-themes 在客户端注入 `class="dark"`，与服务端渲染的 HTML 不一致，会触发水合警告：

```tsx
// app/layout.tsx
export default function RootLayout({ children }) {
  return (
    {/* suppressHydrationWarning 必须加在 <html> 上 */}
    <html lang="zh-CN" suppressHydrationWarning>
      <body>
        <ThemeProvider>{children}</ThemeProvider>
      </body>
    </html>
  );
}
```

不加这行，控制台会报 hydration mismatch 警告。

## Tailwind v4 的 @custom-variant

v4 默认用媒体查询做深色模式。配合 next-themes 必须改用 class 模式：

```css
/* globals.css */
@import "tailwindcss";

/* 声明 dark: 变体基于 .dark 类 */
@custom-variant dark (&:where(.dark, .dark *));

/* 现在所有 dark: 工具类都基于 .dark 类 */
/* <div className="bg-white dark:bg-gray-900"> */
```

## 切换按钮防水合不匹配

切换按钮在服务端渲染时不知道当前主题，直接渲染图标会导致水合不一致：

```tsx
"use client";
import { useEffect, useState } from "react";
import { useTheme } from "next-themes";
import { Sun, Moon } from "lucide-react";

export function ThemeToggle() {
  const [mounted, setMounted] = useState(false);
  const { resolvedTheme, setTheme } = useTheme();

  useEffect(() => setMounted(true), []);

  // 未挂载时渲染占位符，保证水合一致
  if (!mounted) {
    return <button className="h-9 w-9"><Sun /></button>;
  }

  return (
    <button onClick={() => setTheme(resolvedTheme === "dark" ? "light" : "dark")}>
      {resolvedTheme === "dark" ? <Sun /> : <Moon />}
    </button>
  );
}
```

## 代码高亮双主题

Shiki（rehype-pretty-code）支持双主题，通过 CSS 变量切换：

```typescript
// 配置双主题
rehypePrettyCode, {
  theme: {
    light: "github-light",
    dark: "github-dark-dimmed",
  },
  keepBackground: false,
}
```

```css
/* CSS 切换，无需重新渲染 */
code[data-theme*=" "] span {
  color: var(--shiki-light);
}
.dark code[data-theme*=" "] span {
  color: var(--shiki-dark);
}
```

## SEO 考虑

为搜索引擎提供主题颜色提示：

```tsx
// app/layout.tsx
export const viewport = {
  themeColor: [
    { media: "(prefers-color-scheme: light)", color: "#ffffff" },
    { media: "(prefers-color-scheme: dark)", color: "#030712" },
  ],
};
```

## 避免闪烁（FOUC）

next-themes 在 `<head>` 中注入内联脚本，在页面绘制前确定主题，避免深色模式闪烁。这是它比纯 CSS 方案的优势——纯 CSS 的 `media` 查询只能跟随系统，无法记住用户选择。

## 小结

深色模式的完整方案：next-themes 管理状态 + Tailwind v4 `@custom-variant` 声明 + `suppressHydrationWarning` 消除警告 + `mounted` 守卫按钮渲染。每个环节都不能少。
