说实话，我刚开始用Pydantic的时候，就只会用个`Field(default='')`，觉得这就够用了。后来项目做大了，需要处理各种复杂的类型约束、别名、验证逻辑，才发现原来Field()里藏着这么多宝藏。

还有一次，我需要定义好几个模型，里面都有"邮箱格式验证"这种重复逻辑，复制粘贴烦死了。后来发现了Annotated类型，直接把验证逻辑封装起来复用了，那叫一个爽。

今天就把这些实战经验分享给你。

## 01 Field()函数：不只是默认值

很多人用Field()就只知道设个默认值，其实它能做的多着呢。

### 基础用法

```python
from typing import Optional
from pydantic import BaseModel, Field
from pydantic.networks import EmailStr, HttpUrl

class User(BaseModel):
    id: int = Field(..., gt=0, description="用户ID，必须大于0")
    name: str = Field(..., min_length=1, max_length=50)
    email: EmailStr
    website: Optional[HttpUrl] = None
    tags: list[str] = Field(default_factory=list)
    age: Optional[int] = Field(default=None, ge=0, le=150)
```

**Field参数详解**：

- `default`：默认值，最常用的
- `default_factory`：动态默认值，特别适合列表、字典这种可变对象
- `alias`：字段别名，处理API返回的奇葩字段名
- `title` / `description` / `examples`：元数据，生成文档时有用
- `gt` / `ge`：大于 / 大于等于
- `lt` / `le`：小于 / 小于等于  
- `min_length` / `max_length`：长度限制

### default vs default_factory

这个坑我踩过好几次：

```python
# 错误示范：共享默认值
class BadUser(BaseModel):
    tags: list[str] = []  # 所有实例共享同一个列表！

u1 = BadUser()
u1.tags.append('python')

u2 = BadUser()
print(u2.tags)  # 输出: ['python']，惊不惊喜？

# 正确示范：使用default_factory
class GoodUser(BaseModel):
    tags: list[str] = Field(default_factory=list)

u1 = GoodUser()
u1.tags.append('python')

u2 = GoodUser()
print(u2.tags)  # 输出: []，这才对嘛
```

### alias：处理奇葩字段名

有时候API返回的字段名很奇葩，比如用下划线或者全小写：

```python
from pydantic import Field

class User(BaseModel):
    user_id: int = Field(alias='userId')
    full_name: str = Field(alias='fullName')
    
    class Config:
        populate_by_name = True  # 允许用原名赋值

# 用别名创建
user = User(userId=1, fullName='张三')
print(user.user_id)  # 输出: 1

# 也可以用原名（如果配置了populate_by_name）
user2 = User(user_id=2, full_name='李四')
```

## 02 类型系统进阶：玩转复杂类型

### 2.1 Annotated：可复用类型的救星

这个功能简直是为懒人设计的！把常用的验证逻辑封装起来，到处复用：

```python
from typing import Annotated
from pydantic import BaseModel, Field, TypeAdapter
from annotated_types import Gt, Len

# 定义正整数类型
PositiveInt = Annotated[int, Gt(0)]

# 定义短列表类型（最多4个元素）
ShortList = Annotated[list[int], Len(max_length=4)]

# 使用
PositiveList = list[PositiveInt]

ta = TypeAdapter(PositiveList)
ta.validate_python([1, 2, 3])  # 成功
try:
    ta.validate_python([-1])    # 失败：不是正数
except Exception as e:
    print(e)
```

### 实战：封装常用的验证规则

```python
from typing import Annotated
from pydantic import BaseModel, Field, EmailStr
from annotated_types import Gt, Len, Ge

# 常用类型定义
UserId = Annotated[int, Gt(0), Field(description="用户ID")]
ShortStr = Annotated[str, Len(min_length=1, max_length=50)]
LongStr = Annotated[str, Len(min_length=1, max_length=500)]
Age = Annotated[int, Ge(0), Le(150)]
Price = Annotated[float, Gt(0)]

class Product(BaseModel):
    id: UserId
    name: ShortStr
    description: LongStr
    price: Price
    stock: Annotated[int, Ge(0)] = 0

class Order(BaseModel):
    user_id: UserId
    product_ids: list[UserId]
    total: Price
```

一套定义，到处使用，改需求时只改一处！

### 2.2 命名类型别名（Python 3.12+）

Python 3.12引入了`type`语句，定义类型别名更优雅：

```python
from typing import Annotated
from annotated_types import Gt

type PositiveIntList = list[Annotated[int, Gt(0)]]

class Model(BaseModel):
    x: PositiveIntList
    y: PositiveIntList

# 自动生成优化的JSON Schema（使用$defs引用）
print(Model.model_json_schema())
```

### 2.3 自定义类型

有时候内置类型不够用，可以自己定义：

```python
from typing import Any
from pydantic_core import CoreSchema, core_schema
from pydantic import GetCoreSchemaHandler

class Username(str):
    """自定义用户名类型"""
    @classmethod
    def __get_pydantic_core_schema__(
        cls, source_type: Any, handler: GetCoreSchemaHandler
    ) -> CoreSchema:
        return core_schema.no_info_after_validator_function(cls, handler(str))

# 使用
from pydantic import TypeAdapter
ta = TypeAdapter(Username)
result = ta.validate_python('abc')  # 返回Username实例
print(type(result))  # <class '__main__.Username'>
```

### 2.4 处理第三方类型

需要集成第三方库的类型？没问题：

```python
from typing import Annotated, Any
from pydantic_core import core_schema
from pydantic import BaseModel, GetCoreSchemaHandler

class ThirdPartyType:
    """假设这是第三方库的类型"""
    x: int
    def __init__(self):
        self.x = 0

class _ThirdPartyTypePydanticAnnotation:
    @classmethod
    def __get_pydantic_core_schema__(cls, _source_type: Any, handler: GetCoreSchemaHandler) -> core_schema.CoreSchema:
        def validate_from_int(value: int) -> ThirdPartyType:
            result = ThirdPartyType()
            result.x = value
            return result
        
        from_int_schema = core_schema.chain_schema([
            core_schema.int_schema(),
            core_schema.no_info_plain_validator_function(validate_from_int),
        ])
        
        return core_schema.json_or_python_schema(
            json_schema=from_int_schema,
            python_schema=core_schema.union_schema([
                core_schema.is_instance_schema(ThirdPartyType),
                from_int_schema,
            ]),
            serialization=core_schema.plain_serializer_function_ser_schema(
                lambda instance: instance.x
            ),
        )

PydanticThirdPartyType = Annotated[ThirdPartyType, _ThirdPartyTypePydanticAnnotation]

class Model(BaseModel):
    third_party_type: PydanticThirdPartyType

# 支持从 int 自动转换
m = Model(third_party_type=1)
print(m.third_party_type.x)  # 输出: 1
```

这个功能在集成旧系统或者第三方库时特别有用，不用到处改类型定义。

## 03 实战：电商系统的商品模型

来点实际的，看看这些功能怎么用在真实项目中：

```python
from typing import Annotated, Optional, List
from pydantic import BaseModel, Field, field_validator
from pydantic.networks import HttpUrl
from decimal import Decimal
from annotated_types import Gt, Len

# 类型别名定义
SKU = Annotated[str, Len(min_length=1, max_length=50)]
ProductName = Annotated[str, Len(min_length=1, max_length=200)]
Price = Annotated[Decimal, Gt(0)]
Quantity = Annotated[int, Gt(0)]
Description = Annotated[str, Len(max_length=2000)]

class ProductImage(BaseModel):
    url: HttpUrl
    alt_text: Optional[str] = Field(default=None, max_length=200)
    is_primary: bool = Field(default=False)

class Product(BaseModel):
    sku: SKU
    name: ProductName
    price: Price
    cost: Optional[Price] = None
    quantity: Quantity = Field(default=0, description="库存数量")
    description: Optional[Description] = None
    images: List[ProductImage] = Field(default_factory=list)
    tags: List[str] = Field(default_factory=list)
    is_active: bool = Field(default=True)
    
    @field_validator('price', 'cost')
    @classmethod
    def validate_price(cls, v: Optional[Decimal]) -> Optional[Decimal]:
        if v is not None:
            # 保留两位小数
            return v.quantize(Decimal('0.01'))
        return v
    
    @field_validator('images')
    @classmethod
    def ensure_primary_image(cls, v: List[ProductImage]) -> List[ProductImage]:
        """确保至少有一张主图"""
        if v and not any(img.is_primary for img in v):
            v[0].is_primary = True
        return v
    
    def calculate_margin(self) -> Optional[Decimal]:
        """计算利润率"""
        if self.cost and self.cost > 0:
            return ((self.price - self.cost) / self.price * 100).quantize(Decimal('0.01'))
        return None

# 使用示例
product = Product(
    sku='PROD-001',
    name='Python编程：从入门到实践',
    price=Decimal('89.00'),
    cost=Decimal('45.00'),
    quantity=100,
    description='畅销Python教程，适合初学者',
    images=[
        {'url': 'https://example.com/book-cover.jpg', 'is_primary': True},
        {'url': 'https://example.com/book-preview.jpg'},
    ],
    tags=['python', 'programming', 'beginner']
)

print(f'商品: {product.name}')
print(f'售价: ¥{product.price}')
print(f'成本: ¥{product.cost}')
print(f'利润率: {product.calculate_margin()}%')
print(f'库存: {product.quantity}')
```

看到了吗？用了这些高级特性后，模型不仅功能强大，而且代码很优雅。各种约束都在类型定义里，写文档也方便。

## 04 别名的高级用法

### 多个别名

```python
from pydantic import Field

class User(BaseModel):
    user_id: int = Field(alias='userId', alias_priority=1)
    
    # 可以设置多个别名
    username: str = Field(validation_alias=['userName', 'name', 'username'])
```

### 验证时用别名，序列化时用原名

```python
from pydantic import ConfigDict

class User(BaseModel):
    model_config = ConfigDict(populate_by_name=True)
    
    user_id: int = Field(alias='userId')
    full_name: str = Field(alias='fullName')

# 用别名创建
user = User(userId=1, fullName='张三')

# 转字典时用原名
data = user.model_dump()
print(data)  # {'user_id': 1, 'full_name': '张三'}

# 转JSON时也用原名
json_str = user.model_dump_json()
print(json_str)  # {"user_id":1,"full_name":"张三"}
```

## 05 性能优化小贴士

1. **复用Annotated类型**：减少重复代码，修改一处生效所有地方
2. **合理使用default_factory**：避免可变对象的共享问题
3. **TypeAdapter处理列表**：批量验证性能更好
4. **model_construct跳过验证**：已验证数据用这个提升性能

## 总结一下

Field()不只是设默认值，它能：
- ✅ 设置验证约束（gt, lt, min_length等）
- ✅ 定义别名处理不同命名风格
- ✅ 添加元数据（描述、示例等）
- ✅ 管理默认值和工厂函数

Annotated类型让代码更DRY（Don't Repeat Yourself）：
- ✅ 封装常用验证规则
- ✅ 一处定义多处使用
- ✅ 易于维护和修改

自定义类型和第三方类型集成：
- ✅ 扩展Pydantic的能力
- ✅ 无缝对接现有代码
- ✅ 保持类型安全
