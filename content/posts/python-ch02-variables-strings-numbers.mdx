## 变量：给数据起个名字

写程序本质上是处理数据。数据来了，得给它起个名字存起来——这就是**变量**。

```python
message = "Hello Python world!"
```

这行代码的意思是：创建了一个叫 `message` 的盒子，里面装了 `Hello Python world!` 这串文字。以后想输出这串文字，直接用 `print(message)` 就行了。

起名字有几条规矩：

- 只能包含**字母、数字、下划线**
- 不能以数字开头
- 不能有空格（用下划线代替，比如 `user_name`）
- 不能用 Python 自己的词（比如 `if`/`for`/`print` 这些）

另外，变量名要**短又有描述性**。`name` 比 `x` 好，`user_age` 比 `n3` 好。别偷懒写 `l` 或 `O`，因为它们看起来太像数字 1 和 0 了。

## 字符串：文字的处理艺术

字符串就是用引号包起来的一串字符，单引号双引号都行：

```python
"Hello"
'World'
```

**大小写**是最常用的操作：

```python
name = "ada lovelace"
print(name.title())   # Ada Lovelace（首字母大写）
print(name.upper())   # ADA LOVELACE（全大写）
print(name.lower())   # ada lovelace（全小写）
```

`.lower()` 特别有用——用户输入 "Ada" 或 "ADA"，存进来之前先统一转小写，后续比较就不会出错了。

**拼接**也很简单，用 `+`：

```python
first_name = "ada"
last_name = "lovelace"
full_name = first_name + " " + last_name
print("Hello, " + full_name.title() + "!")  # Hello, Ada Lovelace!
```

**空白**是常常被忽略的细节。`\t` 是制表符（类似按了一下 Tab），`\n` 是换行：

```python
print("Languages:\n\tPython\n\tJavaScript")
```

而 `.strip()` 系列用来**去空格**：

```python
name = "  Ada  "
name.rstrip()   # 去掉末尾空格（"  Ada"）
name.lstrip()   # 去掉开头空格（"Ada  "）
name.strip()    # 两端都去掉（"Ada"）
```

注意：`strip()` 这些方法返回新值，不会自动修改原变量，得**重新赋值**才行：

```python
name = name.strip()  # 重新赋值才能永久生效
```

## 数字：算术与类型

Python 做数学运算很直接：

```python
>>> 2 + 3      # 5
>>> 3 - 1      # 2
>>> 2 * 3      # 6
>>> 8 / 2      # 4.0（注意：除法结果永远是浮点数）
>>> 3 ** 2     # 9（乘方，即3的平方）
```

有个细节要记住：**浮点数运算可能有精度问题**：

```python
>>> 0.1 + 0.2
0.30000000000000004
```

这是计算机表示小数的固有局限，实际开发中一般不影响。

还有一个常见报错是**类型错误**——字符串和数字不能直接拼接：

```python
age = 23
# 下面这行会报错！
print("Happy " + age + "rd Birthday!")

# 正确做法：用 str() 转成字符串
print("Happy " + str(age) + "rd Birthday!")
```

## 注释：让代码自己说话

注释以 `#` 开头，Python 会直接忽略它。写注释的目的是告诉读代码的人（也包括未来的你自己）这段代码在干什么：

```python
# 向大家问好
print("Hello Python people!")
```

好的注释解释**为什么要这么做**，而不是简单重复代码在做什么。

## Python之禅：一句话概括

Tim Peters 写了 20 条 Python 编程的指导原则，叫"Python之禅"。在终端输入 `import this` 就能看到全文。我最喜欢的一条是：

> *Simple is better than complex. 简单胜过复杂。*

写代码也是如此——先让它能跑，再慢慢优化。

## 📝 章后习题

学完这一章，来做几道题检验一下吧！

**2-1 简单消息**
将一条消息存储到变量中，再将其打印出来。

**2-2 多条简单消息**
将一条消息存储到变量中，将其打印出来；再将变量的值修改为一条新消息，并将其打印出来。

**2-3 个性化消息**
将用户的姓名存到一个变量中，并向该用户显示一条消息，如"Hello Eric, would you like to learn some Python today?"。

**2-4 调整名字的大小写**
将一个人名存储到一个变量中，再以小写、大写和首字母大写的方式显示这个人名。

**2-5 名言**
找一句你钦佩的名人名言，将名人的姓名和他的名言打印出来。输出应类似于：`Albert Einstein once said, "A person who never made a mistake never tried anything new."`

**2-6 名言2**
重复练习2-5，但将名人的姓名存储在变量 `famous_person` 中，再创建消息存储到变量 `message`，然后打印这条消息。

**2-7 剔除人名中的空白**
存储一个人名，并在其开头和末尾都包含一些空白字符（至少使用 `\t` 和 `\n` 各一次）。打印显示空白，然后分别用 `lstrip()`、`rstrip()` 和 `strip()` 处理并打印结果。

**2-8 数字8**
编写4个表达式，分别使用加法、减法、乘法和除法，但结果都是数字8。输出应为4行，每行都只包含数字8。

**2-9 最喜欢的数字**
将你最喜欢的数字存储在一个变量中，创建一条消息指出你最喜欢的数字，然后将这条消息打印出来。

**2-10 添加注释**
选择你编写的两个程序，在每个程序中至少添加一条注释。

**2-11 Python之禅**
在 Python 终端执行 `import this`，感受一下 Python 的设计哲学。
