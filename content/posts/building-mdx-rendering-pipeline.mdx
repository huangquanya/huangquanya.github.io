# 搭建 MDX 渲染管线：next-mdx-remote 实践

在 Next.js App Router 中用本地 MDX 文件做博客内容源，`next-mdx-remote` 是最灵活的方案。

## 为什么选 next-mdx-remote

两种 MDX 方案对比：

```bash
# 方案 A: @next/mdx —— 文件即路由，MDX 文件本身就是页面
# 适合：MDX 作为页面的场景
# 问题：列表页需要 frontmatter 元数据，处理麻烦
```

```bash
# 方案 B: next-mdx-remote —— 运行时渲染 MDX 字符串
# 适合：内容与路由分离的场景（博客）
# 优势：灵活控制 frontmatter、渲染位置、组件映射
```

博客需要从文件读取 frontmatter 做列表/标签/分页，方案 B 更合适。

## 读取文件 + 解析 frontmatter

用 `gray-matter` 分离 frontmatter 和正文：

```typescript
import fs from "fs";
import matter from "gray-matter";

function readPost(slug: string) {
  const source = fs.readFileSync(`content/posts/${slug}.mdx`, "utf8");
  const { content, data } = matter(source);
  // data 是 frontmatter（title, date, tags 等）
  // content 是纯正文（已剥离 frontmatter）
  return { content, ...data };
}
```

## 渲染 MDX

`next-mdx-remote/rsc` 的 `MDXRemote` 是服务端组件：

```tsx
import { MDXRemote } from "next-mdx-remote/rsc";

export function MDXContent({ source }: { source: string }) {
  return (
    <div className="prose dark:prose-invert">
      <MDXRemote source={source} options={mdxOptions} />
    </div>
  );
}
```

`source` 传入 gray-matter 解析后的**纯正文**，不要传完整文件（含 frontmatter 会导致编译错误）。

## 配置代码高亮

`rehype-pretty-code` 基于 Shiki，配置双主题实现明暗切换：

```typescript
import rehypePrettyCode from "rehype-pretty-code";
import remarkGfm from "remark-gfm";

export const mdxOptions = {
  mdxOptions: {
    remarkPlugins: [remarkGfm],
    rehypePlugins: [
      [rehypePrettyCode, {
        theme: {
          light: "github-light",
          dark: "github-dark-dimmed",
        },
        keepBackground: false,
      }],
    ],
  },
};
```

`keepBackground: false` 是关键——让背景色由 CSS 控制，而非硬编码。

## CSS 切换主题

插件为每个 token 生成 `--shiki-light` 和 `--shiki-dark` 两套变量：

```css
/* 浅色模式 */
code[data-theme*=" "] span {
  color: var(--shiki-light);
  background-color: var(--shiki-light-bg);
}

/* 深色模式（.dark 由 next-themes 添加） */
.dark code[data-theme*=" "] span {
  color: var(--shiki-dark);
  background-color: var(--shiki-dark-bg);
}
```

`data-theme*=" "` 选择器匹配空格分隔的双主题名，切换靠 CSS 变量，**无需重新渲染**。

## 自定义组件映射

覆盖 MDX 默认渲染的 HTML 元素：

```tsx
import Link from "next/link";

export const mdxComponents = {
  // 外链自动加 target="_blank"
  a: ({ href, children }) => {
    const isExternal = href?.startsWith("http");
    if (isExternal) {
      return <a href={href} target="_blank" rel="noopener noreferrer">{children}</a>;
    }
    return <Link href={href}>{children}</Link>;
  },
};
```

## 小结

`next-mdx-remote` + `gray-matter` + `rehype-pretty-code` 的组合，让本地 MDX 博客既灵活又强大：frontmatter 元数据驱动列表/分页/标签，运行时渲染保证内容与组件的动态组合。
